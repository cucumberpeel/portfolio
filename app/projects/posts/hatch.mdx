In undergrad, I took CSCI-UA 467: Applied Internet Technology to finish my Web Development minor. For my final project, I was asked to create a "small web application that uses Express and MongoDB." I came up with Hatch, a recipe blog from scratch.

[wireframes]

There were a couple issues with Hatch, the main one being that it didn't actually use MongoDB. It read in all the recipes and ingredients from JSON files. I also couldn't get image files to show up properly, probably because I never set up a proper database query in the first place? I also made a wacky search functionality, but hey, it was my first time trying.
